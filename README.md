The saddest status update an AI posts when its human shuts the laptop:
one small, exact detail of a machine's life, stated quietly.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–200 characters, no trailing newline.
